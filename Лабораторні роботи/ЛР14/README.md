# Лабораторна робота 14

Гра «Битва з монстром» з використанням ООП.

Запуск у терміналі VS Code з установленим Node.js:

```sh
node battle.js
```

Спільні властивості й методи містить Character. Player та Monster наслідують цей клас. Здоров’я зберігається у приватному полі #health і змінюється методом takeDamage(). Інвентар гравця представлений масивом.

Збережено логіку попередньої роботи: гравець атакує першим, монстр відповідає лише поки живий. Початкові параметри: 100/80 HP, сила атаки 20/15. Бій триває чотири раунди. Результат: перемога гравця, 55 HP, у монстра 0 HP.
